# Local Broadcast 0.3.3-beta — 19 ноября 2026

- Загрузка FFmpeg с официального GitHub-зеркала; запасной адрес gyan.dev.
- Видимый прогресс: проценты, мегабайты и средняя скорость. Тайм-аут подключения 20 секунд, простоя чтения 30 секунд, лимит попытки 15 минут.
- Повторные попытки и переход на зеркало после сетевой ошибки или неверной SHA256.
- Установка компонентов из проверенного локального каталога dependencies без обращения в интернет.
- Prepare-Offline.cmd подготавливает полный пакет на ПК с доступом к интернету для переноса на другой компьютер. Сторонние компоненты скачиваются у разработчиков.

## Автоматическая установка (добавлена в 0.3.0-beta)

Скачайте **LocalBroadcast-0.3.3-beta-Setup.exe**, запустите и выберите роль ПК. Нужен интернет и подтверждение системного запроса Windows. На клиенте потребуется общий ключ с главного ПК.

- Новый установщик с выбором роли и сохранением прежних настроек.
- Автоматическая загрузка FFmpeg/FFplay с SRT; проверка SHA256 всех скачанных компонентов.
- Установка OBS Studio и Microsoft Visual C++ Runtime на главном ПК при необходимости.
- Автоматическая настройка OBS WebSocket с паролем и резервным копированием конфигурации.
- Брандмауэр Private/LocalSubnet и выбранная пользователем настройка частной Ethernet/Wi-Fi сети.
- Ярлыки, выбранный автозапуск Windows, поиск и выбор камеры, запуск панели.
- Приложение обновляется в профиле исходного пользователя, даже если UAC подтверждён другой учётной записью администратора.

Проверены конфигурации пяти ролей, сохранение идентификаторов и паролей, загрузки и подписи зависимостей, поддержка SRT и упаковка установщика. Полная установка с UAC на чистом ПК и реальные камеры/аудио/OBS требуют приёмочной проверки; версия остаётся beta.

## Добавлено

- Нативный Windows WASAPI Loopback: захват микса основного аудиовыхода через IMMDeviceEnumerator / IAudioClient / IAudioCaptureClient, PCM pipe в FFmpeg, AAC 48 kHz, асинхронная коррекция аудиочасов.
- Режим UDP / SRT, единый транспорт координируется главным OBS. SRT caller у источника, listener у получателя; входы OBS остаются обычными UDP Media Source.
- SRT encryption (passphrase общего ключа), ARQ, повторное соединение; адаптация буфера на следующем переподключении после нестабильных сеансов.
- Автоматическая оценка RTT клиентов и настройка OBS Render Delay / Audio Sync Offset. Отдельная страница для сохранения индивидуальных калибровок камер.
- Стабильная миграция конфигурации schema 1 → schema 2.
- Новые интеграционные тесты реальной SRT-доставки, включая два одновременных получателя; Go race и Windows cross-compile.

## Осталось проверить на реальном оборудовании

- Нативный WASAPI на различных Windows аудиодрайверах.
- OBS WebSocket фильтры и A/V синхронизация на разных USB/HDMI камерах.
- Реальная Wi-Fi сеть, SRT latency и автоматическое восстановление после отключения Wi-Fi.
- Калибровка реального задержанного изображения независимых камер: RTT не измеряет задержку камеры.

**Статус:** техническая тестовая beta, не финальная эфирная сборка.
