Быстрый старт

Для первого подключения к главному ПК

  1. На ПК с OBS выберите роль Главный OBS и перезапустите программу.
  2. На остальных ПК выберите нужный профиль и укажите ключ системы, показанный на главном ПК.
  3. Проверьте, что компьютеры находятся в одной сети. При необходимости укажите IP главного ПК.
  4. Приём видео в OBS создаётся через кнопку «Синхронизировать источники» на главном ПК.

Выравнивание источников в OBS

Автоматическая оценка сетевой задержки + сохранённая калибровка камеры и звука

BETA

Система оценивает сетевую задержку по RTT и автоматически создаёт Render Delay и аудиосмещение для каждого входа OBS. RTT не измеряет время экспозиции или задержку USB-камеры. Для точной синхронизации сделайте тест с одновременной вспышкой и хлопком, затем сохраните поправки ниже.

Видео и звук

Если аппаратный кодировщик не запускается, передача автоматически переходит на CPU — x264.
Выберите один монитор или весь рабочий стол. Список относится к этому ПК.
Уменьшает передаваемое изображение и нагрузку на приёмник. Пропорции сохраняются.
Адаптивный: меньше кадров на статичном экране, до 30 при движении. Фактический FPS зависит от нагрузки на ПК. Звук продолжается без перезапуска.
Для звука приложения выберите ниже то устройство, через которое вы слышите его на этом ПК.
HDMI-монитор, Bluetooth-наушники и колонки — разные источники. Если звука нет, выберите нужный явно.

OBS Studio

Транспорт по локальной сети

Главный OBS назначает транспорт для всей системы. При SRT на клиентах используется SRT caller, на получателях — listener. Нужна сборка FFmpeg с libsrt на всех ПК.
Начните с 180–250 мс по Wi-Fi. Это буфер SRT, не суммарная задержка эфира.

Медиакомпоненты

Можно положить ffmpeg.exe и ffplay.exe рядом с LocalBroadcast.exe или указать полные пути. В комплект они не включены.
