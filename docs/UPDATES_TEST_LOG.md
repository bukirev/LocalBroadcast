  Синтетические EXE собраны из текущего кода с разными версиями; это не исторические
  неизменённые поставленные клиенты. В версиях 0.3.3–0.3.5 встроенного updater нет.
- Publisher/изменённый tag pipeline в настоящем GitHub Actions: код подготовлен,
  но новый тег/релиз в этой задаче не публиковался. Локально проверяются синтаксис
  PowerShell, сборка/production validator и установочные тесты.
- Windows x64 чистый ПК, другая физическая машина, обновление во время реальной
  трансляции, антивирус/защищённые каталоги, нехватка диска под настоящей нагрузкой.
- Физическое отключение питания. Журнал/fault injection не доказывают все свойства
  накопителя/файловой системы. Failed/pending cache сохраняется; полного автоматического
  ограничения накоплений после серии отказов пока нет.
- Независимые подписи/Authenticode и key rotation. Доверие ограничено HTTPS,
  фиксированным repo/CDN и SHA-256 относительно metadata GitHub.
- Rollback произвольных миграций данных и намеренное понижение после commit.
- Readiness подтверждает окно/config/localhost listener и доступность медиакомпонентов,
  а не аппаратную, сетевую или многочасовую стабильность.
