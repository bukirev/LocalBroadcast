# Local Broadcast — дорожная карта

- **v0.1.0**: единая программа, роли, discovery, маршрутизация UDP/MPEG-TS, OBS WebSocket интеграция, базовый UI.
- **v0.2.0-beta (текущая сборка)**: нативный WASAPI Loopback, SRT caller/listener remux в local UDP, passphrase, адаптация SRT-буфера после коротких разрывов, расчёт сетевого RTT, фильтры и аудиосмещение OBS, индивидуальная калибровка камер.
- **v0.3.0**: полевые Windows Wi-Fi тесты, диагностика реального SRT packet loss/RTT, алгоритм выбора UDP/SRT, обработка hot-swap аудиоустройств, выбор WASAPI endpoint, стабильный и подробный телеметрический дашборд.
- **v0.4.0**: действительно автоматическая физическая калибровка нескольких камер по общей вспышке/таймкоду, проверка drift и per-frame метаданных, контроль задержки OBS.
- **v0.5.0**: TLS для координатора, доверенное парное сопряжение устройств, подписанные автообновления, совместимость версий, безопасный установщик Windows.
- **v1.0**: полные испытания 2–4 ПК, принятие SLO на задержку/стабильность, длительный эфир и восстановление после сети/аудио/OBS сбоев.

Дорожная карта обозначает **планы**, не гарантии сроков и не наличие уже работающих функций.
